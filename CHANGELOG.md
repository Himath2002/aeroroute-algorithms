# Changelog

All notable changes to AeroRoute Algorithms are documented here.

## [1.0.0] - 2026-07-21

### Added

- Typed airport and route domain values.
- Weighted undirected graph with bounded breadth-first route discovery.
- Generic linked list, circular queue, open-address hash table, and binary heap.
- Heap, median-of-three quick, and merge sorting strategies.
- Three reproducible sample networks and a validated interactive CLI.
- Deterministic benchmark command with correctness checks.
- Focused tests, JaCoCo reporting, GitHub Actions, and dependency maintenance.
- Architecture, workflow, and repository overview visuals.
